# Jellybean Raccoon — Unofficial News Mockup

A responsive, static, WGN-inspired editorial page about **Jellybean**, a raccoon reportedly stuck in an Illinois storm drain grate.

**Important:** This is an unofficial design mockup, not a WGN-TV article. The article text is a fictionalized retelling based on user-provided screenshots. Jellybean is an invented name. The page prominently discloses that it is not affiliated with WGN-TV.

## Deploy with GitHub Pages

1. Create a new GitHub repository and upload all the files and the `assets` directory (or push this folder with Git).
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, then `main`, folder `/ (root)`.
4. Save and open the URL GitHub Pages provides.

For Vercel, import the repository and use the **Other** framework preset; no build command is needed.

## Links

The centered WGN-style logo is the **only external hyperlink** and goes to `https://wgntv.com/`. The blue navigation row contains section labels, not clickable links. The Copy article link button only copies the current page URL.

## Files

- `index.html`: article and page content
- `styles.css`: desktop/mobile styling
- `script.js`: copy-link button
- `assets/`: cropped images from the supplied screenshot
