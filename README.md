# Jellybean News — Fixed, self-contained website

Upload `index.html` to the **root** of your GitHub repository (or drag this project folder into Vercel). All photos, CSS, and JavaScript are embedded directly in this HTML file, so there are no missing image paths or assets to upload.

The WGN-style logo links to https://wgntv.com/. The page is clearly labeled as an unofficial, fictionalized mockup.
